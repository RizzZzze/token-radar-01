Token Radar ranks 198 protocols by the implied value of a future token, estimated from a Huber-robust size curve fit to 119 comparable protocols with recorded market caps. Every row carries an uncertainty band, a FARM, THIN, or SKIP verdict from a costed yardstick, and a concrete farming plan. The bundled dashboard recomputes each number in the browser from the shipped dataset, with no network calls and no hard-coded prices.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
